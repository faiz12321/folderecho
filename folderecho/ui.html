FolderEcho

Compare two folders

See what matches, what is missing, and what changed. Nothing is touched.

Demo. Made-up files, shown as if on your computer. This page cannot touch any real file. The real app runs on your own PC.

Read only. Comparing never changes your files.
Finds files with exactly the same content (a SHA-256 fingerprint of the whole file), even if the names differ. First you see a preview.

Put moved files back where they were. Files that changed, or places that are now taken, are left alone and listed.

What it does and does not do

  • Files match only if their full content is identical (SHA-256). Names and dates are not used to decide.
  • Nothing is deleted. Duplicates move to a holding folder on the same drive. Free space only comes back when you later delete that folder yourself.
  • Skipped and listed: shortcuts and links, hidden and system files, files with several names (hardlinks), unreadable files, and empty files.
  • Not allowed: whole drives, system and program folders, your user folder itself, and cloud-synced folders (OneDrive, Dropbox, Google Drive, iCloud and similar). The same rules apply to the holding folder, so moved files are never uploaded to a sync service. This is a name-based safety check and can miss unusual setups, so only use ordinary local folders.
  • Right before each move, both files are checked again. A file that changed since the preview is not moved.
  • Do not edit or sync the folders while it runs. Many moves are not one all-or-nothing step: if a move is interrupted, Undo still works from the saved journal.
  • Undo never overwrites. Empty folders may stay behind after Undo.
  • Large folders take time because every candidate file is read in full.
  • External drives: duplicates are moved on the same drive as each file (never copied between drives). Only simulated tests so far, not real USB drives or network shares. Try a small test folder first. Undo needs the drive to keep the same letter.
  • Free and open source (MIT license). Provided as is, with no warranty. Keep your own backups of anything important.
